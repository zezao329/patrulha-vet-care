## PROPOSTA DE VALOR
Nós ajudamos donos de pets que buscam cuidado, saúde e bem-estar para seus animais, mas enfrentam dificuldades para encontrar serviços confiáveis e informações claras sobre os cuidados necessários. Oferecemos atendimento completo, profissional e de qualidade, com serviços veterinários, higiene, alimentação e cuidados essenciais, para que os tutores tenham a tranquilidade de saber que seus pets estão em boas mãos, sem correr riscos ou gastar dinheiro com serviços de baixa qualidade.

## DESCRIÇÃO DO NEGÓCIO
Nosso negócio é um pet shop veterinário que oferece cuidado completo e especializado para animais de estimação. Atuamos no mercado pet, proporcionando serviços voltados à saúde, higiene, conforto e bem-estar dos animais.

Nosso principal diferencial é oferecer atendimento especializado, realizado com carinho, dedicação e respeito aos animais, além de contar com uma infraestrutura completa para atender às diferentes necessidades dos pets e de seus tutores.

Nosso público-alvo são donos de animais de estimação que valorizam a saúde e o bem-estar de seus pets, mas enfrentam dificuldades para encontrar serviços confiáveis, informações claras e profissionais que ofereçam um atendimento de qualidade. Essas pessoas buscam segurança e tranquilidade, desejando saber que seus animais estão sendo cuidados por uma equipe preparada e responsável.

Nossa comunicação é acolhedora, confiável e dedicada ao bem-estar animal, buscando criar uma relação de confiança com os clientes e demonstrar o carinho que temos por cada pet.

Nosso principal objetivo é nos tornarmos referência em cuidado animal, oferecendo uma infraestrutura completa, serviços de qualidade e atendimento especializado. Com o crescimento do mercado pet e o aumento da preocupação dos tutores com a saúde e o bem-estar dos animais, encontramos uma oportunidade de oferecer um serviço diferenciado e cada vez mais necessário.

Tudo começou com o atendimento domiciliar. Eu, Dra. Kamila Salgado, e o Dr. Mateus Salgado, ambos formados em Medicina Veterinária, decidimos levar o cuidado até a casa dos tutores porque acreditamos que, no ambiente familiar, o pet se sente mais seguro, tranquilo e confortável.

Durante nossa trajetória, também tivemos a oportunidade de trabalhar em outra cidade do interior do Amazonas. Ao retornarmos para Iranduba, continuamos com os atendimentos domiciliares e percebemos uma necessidade importante na região: a falta de um espaço que reunisse pet shop, banho e tosa e atendimento veterinário em um só lugar.

Foi a partir dessa necessidade e do nosso amor pelos animais que nasceu a Patrulha Vet, com o propósito de oferecer um cuidado completo, especializado e acolhedor para os pets e seus tutores.

## DEPLOY — CI/CD (OBRIGATÓRIO)

O projeto será hospedado em HostGator/cPanel via FTP. Siga TODAS as regras abaixo:

1. Se for Vite: configure `base: './'` em vite.config.(js|ts) para assets relativos
2. Se for Next.js: use export estático (output: 'export'), sem SSR/API routes
3. Se for SPA com rotas, crie `public/.htaccess`:
```
Options -Indexes
RewriteEngine On
RewriteBase /
RewriteRule ^index\.html$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.html [L]
```

4. Crie `.github/workflows/main.yml` com o conteúdo EXATO abaixo (não altere nada):

```yaml
name: Deploy to HostGator via FTP

on:
  push:
    branches: [main]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Instalar dependências
        run: npm ci --legacy-peer-deps || npm install --legacy-peer-deps

      - name: Instalar react-is
        run: npm install react-is --legacy-peer-deps

      - run: npm run build

      - name: Detectar diretório de build
        run: |
          if [ -d "dist" ]; then echo "BUILD_DIR=dist" >> $GITHUB_ENV
          elif [ -d "out" ]; then echo "BUILD_DIR=out" >> $GITHUB_ENV
          else echo "ERRO: dist/ ou out/ não encontrado" && exit 1; fi

      - name: Validar build
        run: |
          test -f "$BUILD_DIR/index.html" || (echo "ERRO: index.html não encontrado" && exit 1)
          grep -qE 'src="/src/|src="\./src/|href="/src/' "$BUILD_DIR/index.html" && echo "ERRO: aponta para /src (source, não build)" && exit 1
          if [ "$BUILD_DIR" = "dist" ]; then
            test -d "$BUILD_DIR/assets" || (echo "ERRO: dist/assets não encontrado" && exit 1)
            grep -q 'src="/assets/' "$BUILD_DIR/index.html" && echo "ERRO: assets absoluto, configure base: './'" && exit 1
          fi
          echo "Build válido: $BUILD_DIR"

      - name: Deploy via FTP
        uses: SamKirkland/FTP-Deploy-Action@v4.3.4
        with:
          server: ${{ secrets.FTP_SERVER }}
          username: ${{ secrets.FTP_USERNAME }}
          password: ${{ secrets.FTP_PASSWORD }}
          protocol: ftps
          port: 21
          local-dir: ${{ env.BUILD_DIR }}/
          server-dir: ${{ secrets.FTP_SERVER_DIR }}
          dangerous-clean-slate: true
          exclude: |
            **/.git*
            **/.github/**
            **/node_modules/**
            **/*.map
```

Secrets necessários no GitHub: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `FTP_SERVER_DIR` (padrão: /)
